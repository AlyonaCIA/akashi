# Security policy

Akashi processes attacker-controlled input by design, so reports are welcome.

## Reporting a vulnerability

Use [private vulnerability reporting](https://github.com/AlyonaCIA/akashi/security/advisories/new).
Do not open a public issue.

Include the affected version or commit, a reproduction, and the impact you observed.
You will get an acknowledgement within seven days.

## Supported versions

Only the latest release receives fixes.
